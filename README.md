# EN3330 Assignment 03

Simple Python scripts for the assignment.

## Run

```bash
pip install -r requirements.txt
python run_all.py
```

## Files

- `common.py` shared functions and plot style
- `q1_dual_primal.py` question 1 plots and checks
- `q2_saddle_point.py` question 2 plots and checks
- `q3_weak_duality.py` question 3 plots and checks
- `run_all.py` runs everything

## Output

The scripts save PNG figures in `figures/`.
